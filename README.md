# Sounds of the Universe

An accessible astronomical exploration application designed to
experience the universe through scientifically grounded audio,
sonification, and auditory descriptions.

The project is intended to support visually impaired users while
maintaining clear distinctions between measured data,
scientific sonification, physical modeling, and interpretive
audio representations.

## Project status

Early development.

The application will progressively incorporate:

- Astronomical objects
- Planetary and stellar environments
- Scientific data
- Data sonification
- Physics-based audio modeling
- Accessible exploration
- Gemini-powered scientific assistance
- Provenance and uncertainty information
